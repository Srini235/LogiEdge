# Build Instructions

This section documents how to build and view the documentation.

## Local preview

Install MkDocs if not already installed:

```bash
pip install mkdocs
```

Then run:

```bash
mkdocs serve
```
```

## Notes

- This documentation is separate from the project runtime and does not affect inference or training behavior.
- Keep docs files in `docs/` and config in `mkdocs.yml`.
