# Repository Structure

This repository is organized by functional areas rather than docs.

- `training/` - training scripts and datasets
- `inference/` - runtime inference service, models, and requirements
- `optimization/` - performance benchmarks and optimization artifacts
- `monitoring/` - model drift detection and monitoring scripts
- `deployment/` - deployment configuration and service definitions
- `hardware/` - hardware-related analysis and justification
- `docs/` - documentation source files for this docs-as-code setup
