# Project Overview

This repository contains the assignment for the Machine Learning on the Edge course.

## Main components

- `training/` - model training code and datasets
- `inference/` - edge inference service and model artifacts
- `optimization/` - benchmarking and model optimization results
- `monitoring/` - drift detection and monitoring scripts
- `deployment/` - deployment manifests and service descriptions
- `hardware/` and `scenario_architecture/` - design documents and architecture analysis
